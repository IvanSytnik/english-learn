Product Vision

Платформа для изучения английского с упором на персонализацию через AI и связку "ученик ↔ репетитор".

Target audience
B2C: взрослые 18–40, уровни A2–C1, цель — работа/иммиграция/путешествия
B2B позже: языковые школы
Core value props
AI понимает где ты слаб и тренирует именно это
Один продукт = self-study + живой репетитор (не нужны два сервиса)
Прозрачный прогресс для ученика и репетитора
North Star Metric

Weekly Active Learners with ≥3 completed sessions

Key metrics
Activation: завершил 1-й diagnostic test + 3 упражнения в первые 7 дней
Retention: D7, D30
Tutor metrics: tutor occupancy, student NPS per tutor
Revenue: ARPU, LTV, MRR
Monetization (план)
Free: ограниченная база знаний + 5 упражнений/день
Pro ($9.99/mo): unlimited AI, full база, аналитика
Pro + Tutor: Pro + N часов с репетитором (marketplace fee 20%)
